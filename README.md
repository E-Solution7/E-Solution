# E-Solution — বাংলা সেবা পোর্টাল (ফ্রন্টএন্ড)

## ফাইল
- `index.html` — হোমপেজ (ডিজাইন অনুযায়ী)
- `service.html?id=land` — সেবার বিস্তারিত (ডেটা থেকে তৈরি)
- `apply.html` — আবেদন-সহায়তা ফরম (ডেমো)
- `page.html?p=contact|privacy|terms|login|register|admin` — সাধারণ তথ্য পাতা
- `css/style.css` — সব স্টাইল
- `js/data.js` — সেবা, আপডেট, হটলাইন, WhatsApp: **এখানেই সব বদলান**
- `js/layout.js` — হেডার, ফুটার, মোবাইল মেনু
- `js/home.js`, `service.js`, `apply.js`, `page.js` — পেজ লজিক

## চালানো
`index.html` ডাবল-ক্লিক করে ব্রাউজারে খুলুন। GitHub Pages/Netlify-তেও সরাসরি আপলোড করা যায়।

## প্রকাশের আগে
1. `js/data.js`-এ আসল হটলাইন, WhatsApp, ইমেইল বসান।
2. সরকারি লিংক ও কাগজপত্রের তালিকা যাচাই করুন।
3. লগইন, অ্যাডমিন, আসল আবেদন জমা ও ট্র্যাকিংয়ের জন্য ব্যাকএন্ড লাগবে (এখন ডেমো)।
4. হিরো ছবির জায়গায় চাইলে নিজের ইলাস্ট্রেশন (`<svg>` বদলে `<img>`) বসান।
